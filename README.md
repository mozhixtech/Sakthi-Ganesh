### 🚀 How to Run & Preview the Website

#### Method 1: Direct File Open
Simply double-click `index.html` in your file explorer to open it in any web browser (Chrome, Edge, Safari, Firefox). All CSS, icons, and client images work out of the box.

#### Method 2: Local HTTP Server (Node.js)
```bash
npx serve . -p 3000
```
Then visit `http://localhost:3000` in your browser.

#### Method 3: Python Server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
